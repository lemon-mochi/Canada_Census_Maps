# How I got the 2011 NHS Data for DAs #

I was not able to find 2011 NHS data for dissemination areas on Satistics Canada's official website. Luckily, I was able to find it on another [website](https://borealisdata.ca/file.xhtml?fileId=7750&version=6.3). The data also contains NHS data for Provinces, census divisions, and census subdivisions. Since it contains all this data, it is simpler to download this file, rather than the individual data for provinces, and other geographic levels. Unfortunately, the data was in an `.IVT` format. I have never heard or seen this file format before. Apparently, this file format is commonly used by Statistics Canada and files can be viewed using something called beyond 20/20 browser (only available on Windows). However, that application seemed to be too old, and did not run on my device. There is a package in R, `canivt` [source](https://doodles.mountainmath.ca/posts/2026-07-28-introducing-canivt/) that can convert `.IVT` to `.csv` so that I can preform data preprocessing on them in Python. However, that only worked for 2021 data, which made it basically useless for this project. After spending more time online to find how to install the beyond 20/20 browser program. I found an archive of a download link that works [here](https://web.archive.org/web/20160804181508/http://www2.beyond2020.com/SC/ProBrowser.exe). Unfortunately, I was not able to convert the `.IVT` file to `.csv`. So, I decided that for 2011 NHS data would not be available for dissemination areas. I am sorry if you wanted to view this information. However, I was able to find an API that has the data, and it can be put into a `.csv` format. That is what `backend/get_2011_nhs_data.py` does. You can try running, but it will take multiple days to complete as there are daily limits on the API. Unfortunately, this also did not work. The only way I can possibly get this data to work is to reverse engineer the `.IVT` file into a `.csv` format, or to manually copy and paste the data from the `.IVT` file into a `.csv`. I found out you could filter the `.IVT` file by province and geographic level. I went back to the beyond 20/20 browser. If you filter by province and only keep the dissemination areas, the data becomes smaller, making it possible to export to a `.csv`. I thought I would filter by province and then create a `.csv` file for each province. I was worried that Quebec and Ontario would have too many dissemination areas and would need to split even further. My worry was correct. The only way to filter multiple areas is to manually add dissemination areas by census divisions manually using the find and expand feature in the 'Dimension' tab at the top. There is no way of knowing whether too many columns were selected without once trying to export to `.csv`. If the export fails, the entire program crashes, meaning I had to go and manually select the census divisions again after re-opening the program. Additionally, there is no undo button, meaning one mistake and you have to go all the way back to manually selecting the census divisions. I hope you appreciate the extent I had to go to get this data. I have now realized that the 2011 NHS data for dissemination areas does not split into male and female. So, that data will not be available. Sorry. Also, a few weeks later, the official download link is working now. [Here](http://www.beyond2020.com/media/downloads/SC/ProBrowser.exe). This version is slightly more advanced but still unable to convert to `.csv` in one go.
